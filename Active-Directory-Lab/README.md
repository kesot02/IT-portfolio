# Active Directory Home Lab

## Project Overview

This project documents my existing Active Directory home lab and its ongoing expansion.

The goal is to strengthen my knowledge of Windows Server, Active Directory Domain Services (AD DS), identity management, Group Policy, and enterprise infrastructure.

In my professional Tier 2 IT support role, I use Active Directory to look up directory information. This lab allows me to develop additional hands-on administration skills in a controlled environment.

## Lab Objectives

- [ ] Document existing Active Directory environment
- [ ] Review domain controller and DNS configuration
- [ ] Create and manage Organizational Units (OUs)
- [ ] Create test users and security groups
- [ ] Configure and test Group Policy Objects (GPOs)
- [ ] Join Windows clients to the domain
- [ ] Practice account and permissions troubleshooting
- [ ] Document lab configurations with screenshots

## Project Phases

### Phase 1: Environment Assessment

Identify existing virtual machines, server roles, domain configuration, and network settings.

### Phase 2: Active Directory Administration

Create a fictional organization with departments, users, and security groups.

### Phase 3: Group Policy

Configure and test policies for users and computers.

### Phase 4: Troubleshooting

Simulate common domain issues and document how they are resolved.
